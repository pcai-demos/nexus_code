## Summary

Merchants can now ask for a refund of a captured card payment through the
API. `requestRefund` checks the refund against the captured payment, sends it
to the card scheme gateway and records it in the `refunds` table. The gateway
times out now and then, so the call is retried up to three times.

## Changes

- `services/refund-api/src/refund-service.ts` (new): `requestRefund`.
- `services/refund-api/src/audit-log.ts`: adds the `REFUND_REQUESTED` audit action.
- `services/refund-api/package.json`: adds `async-retry` for the gateway retries,
  and its types.

## Testing

Tested by hand against the gateway sandbox with test cards: a full refund, a
partial refund, and a refund larger than the capture (rejected). Unit tests
for `requestRefund` will follow in a separate pull request so this one stays
small. The existing tests pass.
